# Study Mylio's behaviour only; implement from scratch

We use the REA MCP to understand how Mylio behaves (features, flows, data layout), then write our own implementation. We copy none of Mylio's code, assets or UI artwork, bypass no licence or login checks, and do not ship under the Mylio name. This keeps the project inside REA's own responsible-use terms and clear of copying proprietary software; the cost is that we reimplement rather than lift.

Scope is private family use on a self-hosted server, not public or commercial distribution.
